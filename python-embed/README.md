# Python Helpers

This directory contains the Python helpers used by the monolith ingestion pipeline:

- `add_book.py`
- `embed_sentences.py`
- `align_sentences.py`
- `align_sentences_dp.py`

`add_book.py` is responsible for ingestion and embedding, it:

1. submits ingestion jobs to the running backend
2. waits for job completion
3. optionally generates natural/literary translated editions from an ingested source edition
4. imports missing dictionary entries for source-language book terms
5. runs embedding and alignment helpers
6. verifies the result in PostgreSQL

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

For production-style Docker deployments, the same scripts can be run through
the `ingest-runner` profile in the root `docker-compose.prod.yml`. This avoids
installing the Python/NLP dependencies on the host and reuses a Docker volume
for downloaded model files. Put Kaikki/Wiktextract dictionary JSONL files in
`DICTIONARY_DIR` on the host, for example
`./dictionaries/kaikki.org-dictionary-German.jsonl.gz`, to enable automatic
dictionary warmup. Put non-committed EPUB/TXT files under
`INGESTION_MANIFEST_DIR` on the host, for example
`./ops/ingestion/books/my-book-de.txt`; the runner uploads local files through
the app admin upload endpoint:

```bash
scripts/ingest-prod.sh \
  --work "Metamorphosis" \
  --year 1915 \
  --author "Franz Kafka" \
  --original-lang de \
  --edition "lang=de,file=classpath:books/metamorphosis_de.epub" \
  --edition "lang=en,file=classpath:books/metamorphosis_en.epub" \
  --aligner dp \
  --reset-existing
```

For repeated deployed imports, keep book metadata in a manifest mounted as
`/ingestion`:

```bash
scripts/ingest-manifest-prod.sh books.local.json
```

In manifests, put `generate` on an edition instead of `file` when the target
edition should be created from another language:

```json
{
  "lang": "en",
  "generate": {
    "source": "de",
    "publisher": "Generated by multilang-reader"
  }
}
```

Generated literary translations are supported for short stories and novellas:

```bash
python add_book.py \
  --work "Metamorphosis" \
  --year 1915 \
  --author "Franz Kafka" \
  --original-lang de \
  --edition "lang=de,file=books/metamorphosis_de.txt" \
  --generate-edition "lang=en,source=de,translator=AI literary translation" \
  --generate-max-source-chars 120000 \
  --generate-chunk-max-chars 1800 \
  --aligner dp
```

The generated edition uses `/api/admin/translate/literary`, so admin ingestion
must be enabled and `MLR_ADMIN_TOKEN` must be available to the runner. Use
`--generate-dry-run` to estimate paragraphs, source characters, and request
chunks before calling the translation provider.

## Environment

Database access for embedding/alignment:

```bash
export DATABASE_URL="postgresql://mlr:mlr_password@localhost:5432/mlr"
```

Optional API base URL override for ingestion job submission:

```bash
export MLR_API_BASE_URL="http://localhost:8080"
```

Optional dictionary directory override:

```bash
export DICTIONARY_DIR="/dictionaries"
```

Optional ingestion source directory override:

```bash
export INGESTION_DIR="/ingestion"
```

## Example

Run from `python-embed/` with the monolith app already running:

```bash
python add_book.py \
  --work "Faust (Part I)" \
  --year 1806 \
  --author "Johann Wolfgang von Goethe" \
  --original-lang de \
  --edition "lang=de,file=classpath:books/faust_de_1.epub" \
  --edition "lang=en,file=classpath:books/faust_en_1.epub" \
  --align-src de \
  --align-tgt en \
  --aligner dp
```

Dictionary warmup is enabled by default. It imports only missing terms for the
source/original language into each aligned target language when a matching JSONL
file is present. Use `--no-dictionary-auto` to skip it, or pass an explicit file:

```bash
python add_book.py \
  --work "Faust (Part I)" \
  --original-lang de \
  --edition "lang=de,file=classpath:books/faust_de_1.epub" \
  --edition "lang=en,file=classpath:books/faust_en_1.epub" \
  --dictionary "source=de,target=en,jsonl=/dictionaries/kaikki.org-dictionary-German.jsonl.gz"
```
